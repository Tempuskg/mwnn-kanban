# MWNN Kanban Pro development stub

This private, no-op package lets contributors exercise the free extension's optional Pro-package loading boundary without access to the private package registry.

From the free repository root, run `npm run link:pro-stub`. The command builds this package and links it as `@tempuskg/mwnn-kanban-pro` without saving the link to the root manifest or lockfile.

The stub intentionally registers no paid features and performs no license checks.
